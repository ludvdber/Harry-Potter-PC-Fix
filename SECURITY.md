# Sécurité / Security

Ce correctif est une DLL chargée dans le jeu : un défaut peut toucher la machine du joueur. Si vous en trouvez un, **ne
l'exposez pas dans une issue publique** : utilisez **Security** → **Report a vulnerability** sur https://github.com/ludvdber/Harry-Potter-PC-Fix/security.

This fix is a DLL loaded into the game: a flaw can reach the player's machine. If you find one, **do not describe it in a
public issue**: use **Security** → **Report a vulnerability** at https://github.com/ludvdber/Harry-Potter-PC-Fix/security.

Seule la dernière release est suivie. / Only the latest release is supported.
